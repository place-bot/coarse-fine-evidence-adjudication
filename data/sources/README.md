# Sources and attribution

This private course repository shares normalized data and stratified pilot samples for academic use. The preprocessing changes whitespace and offsets, projects labels into the coarse task categories, and selects a subset for evaluation. Original corpus terms apply.

- **MIME.** The Misunderstandings in Math Explanations dataset from Scott Crossley and collaborators. Real training responses, using the label suffix for the three-way task. The authors identify CC BY-NC 4.0 in their release. [Dataset and credits](https://github.com/scrosseye/mime_dataset) · [License](https://creativecommons.org/licenses/by-nc/4.0/).
- **SciEntsBank and BEETLE.** Myroslava Dzikovska, Rodney Nielsen, and colleagues, SemEval-2013 Task 7. The normalized files and subsets derived from these corpora are shared under CC BY-SA 3.0. [Release](https://github.com/myrosia/semeval-2013-task7) · [Original attribution](SemEval_attribution.md) · [License text](SemEval_license.txt).
- **DDI.** María Herrero-Zazo, Isabel Segura-Bedmar, Paloma Martínez, and Thierry Declerck, *The DDI corpus* (2013). We use the BLURB development document list. The project spells the original label `advise` as `advice`. [Authors’ corpus and licensing](https://github.com/isegura/DDICorpus) · [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) · [BLURB](https://microsoft.github.io/BLURB/tasks.html).
- **ChemProt.** Martin Krallinger and colleagues, BioCreative VI Chemical–Protein Interaction Track (2017). This repository includes stable identifiers, labels and reconstruction code. The downloader obtains the text from the corpus release. [Dataset and access](https://huggingface.co/datasets/bigbio/chemprot) · [Annotation guidelines](https://zenodo.org/records/4957138).

[Download URLs and SHA-256 digests](download_manifest.json) identify the versions used.
